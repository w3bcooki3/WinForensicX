WinForensicX 3.3.0: parser accuracy and event detections

Parsers
- Built-in .evtx reader: CRC-checked chunks, headerless files, inline and
  shared templates, arrays, embedded Sysmon data, unnamed parameters, and
  older records recovered from slack (marked Recovered). Used on Linux/macOS
  and on Windows when the event API cannot open a file. Matches libevtx on
  37,364 records from 278 public attack-sample logs.
- Prefetch v17/23/26/30/31 including compressed Windows 10/11 files (XPRESS
  Huffman): run count, last eight run times, volumes, loaded files, full
  program path. One timeline entry per run. Matches libscca 62/62.
- SQLite: -wal applied (committed frames only), quoted names, table-level
  primary keys, defaults, REAL affinity. 1,128 tables match SQLite.
- Shell items: users property views, property stores, ZIP folders, more
  known folders. 16,031 items match libfwsi.
- Registry: ShimCache and BAM/DAM from every control set, UserAssist XP
  entries, REG_SZ cut at the first NUL. 1,170,935 keys match libregf.
- Sigma YAML follows the spec (comments, escapes, multi-line and block
  scalars): 3,779/3,779 SigmaHQ rules parse identically to PyYAML.
- Fuzzing with corrupted files: three numeric overflows in the browser
  history reader fixed.

Detections
- Event rules can test individual fields (match, matchNot, differ) with
  alternatives such as Image|NewProcessName; titles name the program, key or
  account.
- 47 new rules: DCSync, DSRM, SID history, boot debug/test signing, GetSystem
  and bare-command services, PsExec/Impacket pipes and admin-share copies,
  tunnelled RDP, KrbRelayUp, pass-the-hash logons, LSASS access, silent-exit
  dumps, NTDS copies, xp_cmdshell, process tampering, WMI subscriptions,
  unsigned drivers, remote threads, shellcode access, dump files, Startup
  drops, sideloaded/planted DLLs, Office and server processes starting
  shells, WMI execution, UAC bypasses, masquerading and renamed binaries,
  weakened settings, persistence keys, SAM/LSA edits, port proxies, MRU
  wiping, privilege-escalation pipes, BITS, shims, Winsock LSPs, BlueKeep
  probes, stopped logging services.
- More event IDs collected, each query with its own cap.
- Attack-sample logs with at least one finding: 84 -> 201 of 278.

Tests and the scenario suite are not updated in this push.
