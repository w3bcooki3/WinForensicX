WinForensicX 3.2.0: process trees, log integrity, $MFT, SRUM, fleet movement

Includes 3.1.0 (not pushed separately).

Engine (3.2.0)
- Process trees rebuilt from Sysmon 1 (process GUID), 4688 (process ID and
  start time, so reused IDs are not taken for the parent) and the process
  list; findings carry their ancestry and the case file shows it as a tree.
- Event-log integrity: clock set back while a log was recording, a busy
  Security or Sysmon log falling silent while other logs kept recording,
  Sysmon stopped or reconfigured. Sysmon events 4 and 16 are collected.
- $MFT parsing from collected files: programs, scripts, archives and
  shortcuts, deleted records, ADS, download origin (Zone.Identifier), and
  timestomp detection (SI vs FN times) in user-writable folders.
- SRUM (SRUDB.dat) through a new read-only ESE reader: network and disk bytes
  per program and user; large uploads by exfiltration tools or programs that
  do not usually upload are reported.
- Fleet report: movement between hosts (remote logons in, explicit
  credentials and SMB/RDP/WinRM/RPC/SSH out), machines not yet triaged, and
  programs recorded on only one host. result.json carries compact Programs,
  Logons and Addresses summaries; host info records its own addresses.
- Fleet report times stay UTC on PowerShell 7 (JSON dates were read back as
  local-format text).

Report and pages (3.1.0)
- Case report redesigned: masthead, summary, chart of when it happened,
  incidents with a likely starting point, and a case file per finding (what
  happened, when, how we know, what to do). Print gives every case file with
  running headers and page numbers. All times UTC.
- Explore views in the browser, fleet report, in-tool help and field guide
  share the same design.
- Corroboration: independent sources that saw the same program, with the
  earliest trace; two or more raise confidence one level.
- ATT&CK names for T1566 (.001, .002) and T1189.
- %SystemRoot% paths were flagged as masquerading (fixed).

Tests and the scenario suite are not updated in this push.
